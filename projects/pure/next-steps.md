# 后续工作入口

当前用户只要求把经验和工程做成开源仓库，**暂不开始全剧情汉化，也暂不做陌生 Agent 接手验收**。
以下是将来获得对应任务后可执行的顺序，不是已完成清单。

## 首先确认环境和冻结版本

运行 doctor，校验用户提供的日版哈希，从源码重建 P05 并核对固定输出。
正常的工程自检不等于独立 Agent 接手验收；后者需要以后单独安排。

## 若用户以后启动正文阶段

1. 建立原文字形 ID → 日文 Unicode 的完整映射；目前只有字体位图和已识别的界面文本。
2. 在已知正文区域验证 `FE` 记录、控制码和分支目标，形成可复现导出，不把约 5,852 条候选直接当成唯一真实记录表。
3. 整理人名与术语：三上智也、桧月彩花、今坂唯笑、伊吹美奈裳；唯笑昵称“阿智”。保留 Pure 原版年龄，不能套用高中时期资料。
4. 先做一段正文的独立实装实验，尤其核对 `0x42A8` 等正文入口状态与存读档恢复位置。
5. 规划新文本与中文字库空间。P05 固定区无法容纳全文，不能直接继续递增现有 cursor。
6. 做成可重复的小批量生成、缺字/分页诊断、分支回归后再批量翻译。
7. 单独维护新范围的输出哈希、翻译状态与检查证据，不覆盖 P05。

## 可单独开展的兼容性研究

Native 黑底开场叙述不可见：用日版与 P05 在同核心、同 HLE/参数下作对照，比较 tilemap、字体缓冲、
调色板与显示窗口。现在只有失败现象，没有定位根因；不要先改 ROM 来“修好录像”。
