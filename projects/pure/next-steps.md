# 复用与验收检查表

本仓库记录可复用工具与工程经验，不作为私有汉化项目的进度日志。
继续实际游戏项目时，由使用者在私有目录维护输入清单、字表、译文、审校状态和输出哈希。

1. 验证原始 ROM 哈希；保留原件与冻结版本，实验输出和存档独立。
2. 逐字核对字形 / 上下文，校验可变长控制操作数；字节回编不能替代语义验证。
3. 私有译文输入必须精确保留控制码 / 换行顺序；检查字号、定位、窄字距、动态插入和缺字。
4. 扩容时同步核对 Flash 擦除块、保存地址、读取地址及工厂空态；保留区不得放正文或字库。
5. 对最终输出重新运行分支、合法时钟、普通存读档、覆盖、通关标志、画廊及初始化回归。
6. 区分静态候选、实际到达、画面抽检、语义校对和完整历史组合，不将单条小样概括为全游戏通过。
7. 公开提交前检查：示例须自造；实际文本 / 字表 / ROM / BIOS / 截图 / 存档 / 私有路径不可新增到 Git。

## 独立兼容性研究

Native 黑底正文不可见应先以原版、冻结版和同核心 / BIOS / 参数对照，再比较图块、字体缓冲、
调色板和显示窗口。不要先改 ROM 来“修好录像”；该原版已有的问题不能冒充本次已解决。
