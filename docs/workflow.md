# 汉化工作的实际顺序

1. **保护基线。** 记录大小与哈希，原件只读使用，单独保存输出。
2. **实际运行。** 查看标题、菜单、正文、保存/读取；建立界面清单，明确当前 BIOS、核心和输入方案。
3. **动态追踪。** 从屏幕上的一段文字反查读取、绘制函数和字体访问，而不是先猜一大片字节是文本。
4. **最小实验。** 修改一小处已定位文本，确认显示、分页、返回和操作没有损坏。
5. **形成流水线。** 文本与控制码分离；字形去重和编码；受保护重定位；输出补丁、哈希和重建入口。
6. **按修改验证。** 版面看实际截图；保存要跨进程读回；动画要逐帧看，不能只看静止终帧。
7. **冻结与后续。** 定稿保留可复现入口；新范围另开输出。实际游玩发现的问题再定向修订。

通用层可以处理哈希、受保护写入、位图和日志。游戏特有的字库格式、控制码、地址及存档行为应放在项目适配器。
本仓库的 12×12 编解码器来自 Pure/Cure 工程经验，不表示所有 NGP 游戏都使用这一格式。
